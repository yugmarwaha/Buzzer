# components

## Purpose
Shared UI for the Host app: presentation-only primitives under `ui/`, the host-screen charts under `charts/`, plus two T7 components for the `pin_drop`/`closest_guess` question types.

## Contents
- ui/button.tsx — `Button` component; `variant` (`primary`/`secondary`/`outline`/`ghost`/`danger`/`glass`; `default` and `destructive` are older names for `primary` and `danger`), `size` (`sm`/`md`/`lg`/`xl`, sized for a projector) and `loading` (shows a `Spinner`) map to token-based classes via `cn`. Base is `rounded-lg font-semibold` with a `focus-visible:` ring recipe (`ring-ring`, 2px, offset in `ring-offset-page`). Disabled state is a muted label on `bg-raised` with `pointer-events-none` — not opacity.
- ui/card.tsx — `Card`, `CardHeader`, `CardContent`, `CardFooter`, `CardTitle`, `CardDescription`. `Card` has a `variant`: `default` (`rounded-xl border border-line bg-surface shadow-card`), `raised`, `glass`/`glass-strong`/`glass-subtle`, `interactive` (`.lift`), and `question` (strong glass with a colored `tone` edge on the `top` or `left`).
- ui/badge.tsx, ui/progress.tsx, ui/spinner.tsx — `Badge` (`tone`, `size`), `Progress` (token bar on `bg-track`), `Spinner` (keeps turning under reduced motion). ui/motion.ts — `staggerStyle(i)`, the entrance delay for item `i`.
- ui/input.tsx — `Input`; a styled `<input>` passing through all native input props: `rounded-lg border-line-strong bg-surface text-primary placeholder-muted` with a `focus-visible:` ring (`ring-ring`).
- ui/TimerBar.tsx — `TimerBar`; renders a 120px timer dial (SVG ring, `role="timer"`, `aria-live="off"`): the arc starts at 12 o'clock and shrinks anticlockwise, with the seconds number inside. The arc uses `stroke-timer-1` above 75% of the time limit, `stroke-timer-2` above 40%, then `stroke-timer-4`, on a `stroke-timer-track` ring. The number pulses (`animate-pulse-soft`, red) in the last 5 seconds. Under reduced motion the dial moves once per second. Takes `totalSeconds`, optional `initialSeconds` (for resuming display after reconnect), and `paused`.
- ui/ThemeToggle.tsx — `ThemeToggle`; light/dark switch (lucide `Sun`/`Moon`). Calls `window.buzzerTheme.set()` from the inline script in `index.html` (which owns the `buzzer-theme` localStorage key and the OS-preference listener; falls back to setting `data-theme` directly) and watches `data-theme` with a `MutationObserver` to keep its label right. Props: `variant` (`icon` default, a 48px square for corners; `row` for icon plus label) and `className`. Host mounts it only through `ThemeCorner` in `App.tsx`: fixed top-right on every route except `/game/*`, where it is top-left because End game sits top-right.

- PinGrid.tsx — `PinGrid` canvas for Pin Drop (fixed −5..5 integer grid): optional `selected`/`target` points, optional T8 `imageUrl` background (loaded once, drawn under the grid lines, fitted and centered in the grid square by its natural size, which includes EXIF rotation; a failed load leaves the plain grid), interactive only when `onSelect` is given, `maxSize` cap (520 projector, 240 editor preview). Exports the pixel↔grid conversion (`pointFromPixel`, `pixelFromPoint`) from design `docs/plans/t7-new-question-types.md` §6. Themed per T9 spec §3.10: `tokenColors` reads the token channel triplets once per draw from the root element's computed style (no inline styles written) (surface, line, line-strong, secondary, success, accent, accent-fg), and a `MutationObserver` on `data-theme` triggers a redraw. **The player app has a copy** that must stay identical apart from its header comment.
- QuestionImage.tsx — T8 `QuestionImage` (`id`, `urls`, `alt`, `className`, `eager`): framed `<img>` (`bg-surface border-line rounded-xl object-contain`, never recolored), lazy except the live question; an id with no URL or a failed load shows an "Image unavailable" box. `urlFor(urls, id)` for callers that need the URL itself (PinGrid backgrounds). **The player app has a copy** (same code, different header comment).
- ImagePicker.tsx — T8 editor pieces: `useImageLibrary(courseId)` (the course's current images, loaded once per editor page; `upload` adds to the list), `ImagePicker` (thumbnail + Add/Change, "Older version" note for a `current: false` reference), `ImageChooser` (panel: pick a current image, Upload new, Remove), `ImageThumb`, and `fileProblem`/`formatBytes`/`IMAGE_ACCEPT` (also used by `pages/course/ImagesPage`). It offers only current images, because a new reference must be current (backend 422 otherwise).
- charts/ — host-screen charts in React + inline SVG (`ScoreHistogram`, `AnswerBars`, `QuestionAccuracyChart`, `DonutStat`, `BandBar`, `Sparkline`), imported from the `charts/index.ts` barrel and used by `pages/game/ResultsPage` and `GameOverPage`. See `charts/CLAUDE.md`.
- NewTypeResults.tsx — `NewTypeResults` results summary for both T7 types (target + top-5 points as `Badge`s, or correct value + a `charts/BandBar` of full/partial/miss with counts in its legend; answered count only under COMPLETENESS), used by `pages/game/ResultsPage` (with the grid, larger type, glass panel) and `GameOverPage` (no grid, smaller type); also `isNewType`, `topPins`.

## How it fits in
These are the dumb/reusable building blocks under frontend/host/src; `pages/` (including `pages/game/`) compose them but never the reverse — nothing here imports from `pages/`. `button`/`card`/`input` pull the `cn` class-merging helper from `lib/utils`; `TimerBar` and `ThemeToggle` do not (they build their classes with plain template literals).

## Styling
These primitives follow the theme rules in `frontend/CLAUDE.md` / `docs/plans/ui-themes.md` (sections 3.8 and 12): radius `rounded-lg` for controls, `rounded-xl` for cards, `rounded-2xl` for glass and question cards, `focus-visible:` rings (never `focus:`), token color classes only. Host room-facing text is larger than the other apps' (see the `game/` pages).

## Gotchas
- `PinGrid` uses no CSS border (with border-box sizing a border would shrink the drawing area while `getBoundingClientRect()` still includes it, skewing the tap → grid conversion); its frame and colors are drawn on the canvas from the theme tokens.
- Don't add raw palette classes (`bg-red-500`) or `text-accent` here; use the token classes (`text-accent-text` for accent-colored text). `npm run check:colors` from `frontend/` flags violations.
- TimerBar's countdown interval effect has an empty dependency array (`[]`, i.e. runs once on mount) by explicit design — the code comments that its parent is expected to force a remount via `key={questionId}` per question rather than relying on prop updates to reset the timer. Passing new `totalSeconds`/`initialSeconds` props without changing `key` will not restart it.
- TimerBar's pause/resume logic reconstructs `endTimeRef` from a `frozenRef` snapshot each time `paused` toggles or each tick while paused; it's wall-clock-based (via `Date.now()`), not a simple decrementing counter — relevant if you need it to survive tab backgrounding/reconnects consistently.
- No index/barrel file in `ui/` (only `charts/` has one) — consumers import each `ui/*` file directly (e.g. `../components/ui/button`).
