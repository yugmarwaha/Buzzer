0 How to read this sheet

Layers import downward only. The one exception is marked in red.

LegendBlue = ordinary dependency. Red = a dependency that points the wrong way. Green = frontend.

1 The only link between frontend and backend

Browser→ nginx→ FastAPI + socket.io→ MySQL + Redis
  • /api/* is REST. Frontend: each app's lib/api.ts. Backend: routers/.
  • /socket.io is live play. Frontend: pages/game/GameLayout.tsx. Backend: websocket/gateway.py.

nginxThe single front door. It serves the built React apps and forwards /api and /socket.io to the backend.

2 Backend layers, top to bottom

Read it like a building: each floor only calls on the floors below it. A request comes in at the top and works its way down to the database.

Top
main.pyStarts the app and plugs everything in.Uses: routers, websocket, services, common
↓ calls
Doors
routers/Handles web requests to /api.Uses: services, schemas, models, common
websocket/Handles live game messages on /socket.io.Uses: services, models
↓ calls
Logic
services/The game rules: rooms, scoring, login tokens, exports.Uses: models, schemas, common
↓ calls
Helpers
common/Login checks, error types, logging.Uses: models, services ▲
schemas/The shape of data going in and out.Uses: nothing
↓ calls
Data
models/The database tables.Uses: database
↓ calls
Base
config · database · redisSettings and the connections to MySQL and Redis.Uses: nothing

The one wrong-way arrow: common/dependencies.py reaches up into services/auth_service.py to read login tokens. Everything else points down.

Left outAlmost every floor also uses the Base floor. It's not repeated in each box to keep the map readable.

3 Frontend: three apps, no shared code

hostBig screen. REST + socket.io.
playerPhone. REST + socket.io.
adminConsole. REST only.

Each one is pages/ → components/ui → lib/. Helpers like api.ts and TimerBar are copied into each app.

Copies differPlayer's utils.ts adds isTokenExpired. Admin's api.ts adds upload and download helpers.

4 Watch out for

Copies drift. Fix api.ts in one app and the other two stay broken.

Nothing checks the contract. Socket event names and JSON shapes are hand-written on both sides.

Imports hide inside functions. routers/game.py imports models mid-file, so read the whole file.
